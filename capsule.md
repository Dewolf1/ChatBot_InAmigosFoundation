## 🎯 What Problem Does This Solve?

As InAmigos Foundation grows, website visitors keep asking the **same questions** over and over:

- *"How can I donate?"*
- *"Is the internship paid?"*
- *"Are you a registered NGO?"*
- *"How do I apply?"*

Having humans answer these manually **wastes hours every week**. But simply plugging in ChatGPT has **two critical flaws**:

1. **💸 Cost** — Every single message costs money. At scale, this adds up fast.
2. **🚨 Hallucination** — AI can invent fake policies, wrong registration numbers, or imaginary programs. For an NGO dealing with donations and legal certifications, **one wrong answer can destroy trust.**

---

## 💡 Our Solution: The Hybrid Approach

We built a chatbot that is **smarter about how it answers**. Instead of sending every message to an expensive AI, it uses a **three-layer system**:

### Layer 1: Instant FAQ Matching (Free, Instant, 100% Accurate)
- Every common question is stored in a local knowledge base (`faq.json`) with **84 verified entries**.
- When a visitor types a question, the bot mathematically matches it against this database using **TF-IDF** (a text-matching algorithm) and **direct tag matching**.
- If the match is confident, the bot replies **instantly** with the **exact approved wording**.
- **Cost: ₹0. Speed: Instant. Accuracy: 100%.**

### Layer 2: AI Fallback with Guardrails (For Tricky Questions)
- If the bot isn't confident enough, it calls an AI (GPT-4o-mini or Claude Haiku).
- But it doesn't just forward the question blindly — it sends the **top 3 closest FAQ entries** as context, so the AI stays **grounded in real data** and doesn't invent facts.
- The AI is also instructed to **reject off-topic questions** (like coding, math, or general trivia) and politely redirect focus to the foundation.

### Layer 3: Continuous Learning Loop
- Every question the bot couldn't confidently answer is **automatically logged**.
- The team can review this log weekly and add new FAQ entries to make the bot smarter over time — **no coding required**, just edit a JSON file.

## 🖥️ How It Looks (The Widget)

The chatbot is a **floating widget** that can be embedded on **any website** with a single line of code:

```html
<script src="widget.js" data-api="https://chatbot-inamigosfoundation.onrender.com" data-org="InAmigos"></script>
```

### Widget Features:
- **Welcome Screen** with a greeting and the foundation's name
- **6 Quick-Reply Buttons** on first open:
  - 🏛️ About InAmigos
  - 🎓 Internship Info
  - 💰 How to Donate
  - 🤝 Volunteer
  - 📋 Our Programs

- **Follow-up Suggestions** after every response so users always have something to click

- **Smooth animations** — slide-up window, fade-in messages, pulse on the chat bubble
- **Green "Online" indicator** so visitors feel confident the bot is active
- **Mobile-responsive** design that works on any screen size

## 🛡️ Built-in Guardrails

### Off-Topic Rejection
If someone asks the bot a coding question, math problem, or general trivia, the AI politely declines:

> *"I'm the InAmigos Foundation assistant and can only help with questions about the foundation. Feel free to ask about our programs, internships, or donations!"*

### No Hallucination on Critical Facts
Registration numbers, donation policies, and legal certifications are **never generated by AI** — they come directly from the verified FAQ database.

### Graceful Degradation
If the AI API goes down or no API key is configured, the bot doesn't crash. It returns a safe fallback message directing the visitor to email the team.

```
       └──→ Log unanswered questions for team review
```

## 📋 How to Make the Bot Smarter

1. Open `backend/data/faq.json`
2. Add a new entry:
```json
{
  "id": "your-unique-id",
  "question": "The question visitors might ask",
  "answer": "Your verified, approved answer here.",
  "tags": ["keyword1", "keyword2", "related phrase"]
}
```
3. Push to GitHub → Render auto-deploys → Bot is instantly smarter.

**No coding knowledge required. Just edit the JSON file.**
